# JavaScript Utility Functions

A collection of beginner-friendly **JavaScript functions** for practicing string manipulation, array operations, and number algorithms.

---

## 📂 Functions Included

### 🔤 String Functions

1. **Reverse a String** – Reverses the characters in a string.
2. **Count Characters** – Returns the total number of characters in a string.
3. **Capitalize Words** – Capitalizes the first letter of each word in a sentence.

### 🔢 Array Functions

1. **Find Maximum** – Returns the largest number in an array.
2. **Find Minimum** – Returns the smallest number in an array.
3. **Sum of Array** – Calculates the sum of all elements in an array.
4. **Filter Array** – Filters out elements based on a given condition.

### 🧮 Number Functions

1. **Factorial** – Calculates the factorial of a number.
2. **Prime Number Check** – Checks if a number is prime.
3. **Fibonacci Sequence** – Generates the Fibonacci sequence up to a given number of terms.
